# mobile/

App commands, from `mobile/` (Flutter 3.50.0; Windows: run through PowerShell):

```sh
flutter pub get
dart format --output=none --set-exit-if-changed lib/main.dart lib/data lib/state lib/ui test integration_test
flutter analyze && flutter test
flutter run --flavor development --dart-define-from-file=config/development.json
./tool/android-dev.ps1 help     # emulator setup (Google APIs image)
```

`lib/api/` is generated by `cargo xtask openapi` from `backend/`; do not edit it by hand.

Dart's `HttpClient` ignores Android's `network_security_config`, so development builds trust the dev CA through the `assets/dev/` flavor asset and `devTrust`.
